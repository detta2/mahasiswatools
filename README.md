**Dari Mahasiswa, Untuk Mahasiswa** — Satu Portal Sejuta Solusi Kuliah.

100% di sisi client (browser). Tidak ada data yang dikirim ke server mana pun.

### 📈 Batch Saran Argon #2 — 5 Tool Terakhir (Tool 81–85)

- **Regresi Berganda & Uji Asumsi Klasik** — OLS matriks 1–4 variabel X: koefisien, uji t parsial, uji F simultan, R² & Adjusted R², VIF multikolinearitas, uji Glejser heteroskedastisitas, normalitas residual Jarque-Bera, narasi Bab 4 otomatis.
- **Pembuat Daftar Singkatan Otomatis** — ekstrak akronim dari naskah, kepanjangan dari pola kurung + kamus 60+ singkatan, urut A–Z, ekspor .doc.
- **LPJ & Kas Kegiatan UKM** — muat RAB (format sama dengan Generator Proposal), sesuaikan realisasi per item, sisa dana otomatis, ekspor LPJ resmi berkop.
- **Konverter SKS MBKM** — jam magang/KKN → penyetaraan SKS (45 jam/SKS) + progres target 20 SKS.
- **Lembar Bimbingan Skripsi** — kartu kendali konsultasi: catatan sesi per pembimbing, status Revisi/Lanjut/ACC, ekspor .doc berkop.

## 🎯🖊️💾 Batch Saran Argon #1 (Tool 79–80 + Backup)

- **Kalkulator Target Nilai Mata Kuliah** — bobot komponen dapat diedit, nilai minimal komponen terakhir untuk target akhir + tabel target lain, simpan banyak mata kuliah, unduh Kartu Target PNG.
- **Manajer Revisi Pasca-Sidang** — checklist revisi per penguji (halaman lama/baru), progres %, ekspor Lembar Revisi resmi berkop logo dengan kolom paraf penguji.
- **Backup & Restore Data** — tombol di footer: unduh seluruh data lokal (favorit, ceklis, koding, catatan, dll.) sebagai JSON dan pulihkan di perangkat lain. Penyimpanan kini memperingatkan bila kuota browser penuh.

## 📊🔢 Dua Tool Baru (Tool 77–78)

- **Statistik Deskriptif & Distribusi Frekuensi** — mean/median/modus/SD/kuartil, tabel distribusi frekuensi (Sturges), kategorisasi skor empiris & ideal, narasi deskripsi Bab 4 otomatis. Paket statistik kini lengkap: deskriptif → asumsi → parametrik → non-parametrik.
- **Nomor Halaman & Watermark PDF** — beri nomor halaman (5 posisi, 4 format, opsi lewati cover) dan watermark teks diagonal pada PDF yang di-upload, 100% lokal via pdf-lib.

## 🧪 Tujuh Tool Baru (Tool 70–76)

- **Uji Statistik Non-Parametrik** — Mann-Whitney, Wilcoxon, Kruskal-Wallis, Spearman + narasi Bab 4 (pendekatan normal & chi-kuadrat, koreksi ties).
- **Lembar Persetujuan Responden (Informed Consent)** — dokumen etika penelitian berkop logo, siap tanda tangan.
- **Koding Kualitatif Transkrip** — buku kode berwarna, tandai segmen wawancara, frekuensi tema otomatis, ekspor tabel koding .doc.
- **Daftar Hadir & Berita Acara** — tabel hadir tanda tangan zig-zag format resmi + berita acara, .doc berkop.
- **Generator Ide Judul Skripsi** — pola judul dari variabel X/Y/lokasi untuk 6 jenis penelitian.
- **Kalkulator Target Biaya Kuliah** — total sisa biaya → target tabungan per bulan/minggu/hari + progress bar.
- **Generator Soal Rumpang (Cloze)** — soal isian otomatis dari teks materi (mode kata kunci/berkala) + kunci jawaban.

## 📈📝📚 Tiga Tool Baru (Tool 67–69)

- **Uji Statistik Inferensial** — normalitas Jarque-Bera, uji-t independen & berpasangan, ANOVA satu arah, regresi linear + korelasi, lengkap dengan **narasi interpretasi otomatis gaya Bab 4** (nilai p dihitung via fungsi beta inkomplet, terverifikasi terhadap hitung manual).
- **Pembuat Kuesioner Penelitian** — item Likert 4/5, pilihan ganda, dan terbuka; preview berkop logo; ekspor .doc bertabel skala dan teks siap tempel ke Google Form.
- **Pencari & Rak Jurnal** — cari publikasi via **OpenAlex**, buat sitasi otomatis dari **DOI (Crossref)**, simpan ke rak referensi lokal, ekspor **Daftar Pustaka APA 7** (.doc) dan **BibTeX** untuk Zotero/Mendeley.

## 📑 Generator Proposal (Tool 66)

Tiga jenis proposal dalam satu tool — **Penelitian/Skripsi** (BAB I–III lengkap), **Kegiatan Mahasiswa** (susunan acara, kepanitiaan, **RAB terhitung otomatis**), dan **Magang/PKL** — cover berlogo institusi, preview kertas live, lembar pengesahan, ekspor **.docx asli** margin 4-4-3-3.

## 🤖 Kit Anti-AI & Keaslian (Tool 60–65)
60. **Pendeteksi Gaya Tulisan AI** — skor risiko dari burstiness (CV panjang kalimat), type-token ratio, 30+ frasa klise LLM (ID/EN), grafik batang kalimat & sentence heatmap.
61. **Humanizer & Editor Variasi Kalimat** — editor per kalimat, analisis ritme (peringatan 3 kalimat mirip beruntun), kamus klik-ganti 58 kata klise AI → sinonim akademik natural.
62. **Pembersih Jejak AI** — pindai & bersihkan zero-width chars, NBSP, em-dash, kutip melengkung, sisa Markdown.
63. **Verifikator Keaslian Daftar Pustaka** — fetch nyata ke Crossref REST API per sitasi (atau via DOI), skor kemiripan judul, flag potensi halusinasi AI; status offline dibedakan dari tidak ditemukan.
64. **Generator Deklarasi Penggunaan AI** — pernyataan dwibahasa (skripsi kampus ID + jurnal internasional EN), ekspor .doc.
65. **Editor Bukti Ketikan Mandiri** — telemetri lokal (ketukan, koreksi, paste, waktu aktif, snapshot 10 detik) di localStorage + ekspor Sertifikat Bukti Penulisan (.doc) berisi linimasa pertumbuhan naskah.
Arsitektur sesuai brief: lazy-load library (JSZip/PptxGenJS/pdf-lib/QR/Tesseract), Web Share API (tombol bagikan di tool kelompok/teks), back-button trap (tombol back HP menutup modal), panel modal bottom-sheet dengan dvh, statistik hero dinamis dari katalog.

## Teknologi
