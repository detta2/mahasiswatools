# MahasiswaTools 🎓

**Dari Mahasiswa, Untuk Mahasiswa** — Satu Portal Sejuta Solusi Kuliah.

Portal utilitas akademik 100% gratis, tanpa login, tanpa watermark, dan berjalan
100% di sisi client (browser). Tidak ada data yang dikirim ke server mana pun.

🌐 **Live:** https://detta2.github.io/mahasiswatools/

## Fitur Aktif (15)

1. Uji Validitas & Reliabilitas Kuesioner + Auto-Narasi Bab 4
2. Konverter Skala Likert Massal
3. Kalkulator Sampel (Slovin, Isaac–Michael, Lemeshow)
4. Pembersih Teks Copy-Paste PDF
5. Generator Daftar Pustaka (APA 7, MLA, Harvard, Vancouver)
6. Auto-Italic Kata Asing & Pengecek Kata Berulang
7. Case Converter EYD Judul Bahasa Indonesia
8. Pre-Turnitin Similarity Checker (lokal, Jaccard 3-gram + highlight)
9. Teleprompter & Timer Latihan Sidang
10. Simulator Target IPK (GPA Planner)
11. Pengacak Kelompok Adil
12. Splitter Kas & Patungan Kelompok/KKN
13. Generator Chat Dosen & Surat Kampus
14. Konverter Terbilang Rupiah & Angka Romawi
15. Kalkulator Budget Harian Anak Kos

Plus 40 tool lain terdaftar di katalog untuk diaktifkan pada tahap berikutnya.

## Teknologi

Satu file `index.html` — HTML + Tailwind CSS (CDN) + JavaScript murni.
Preferensi (favorit, tema, daftar pustaka) disimpan di `localStorage`.
